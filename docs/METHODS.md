# Methods

## Data-generating process

Each sequence is generated by a four-state HMM. At time `t`, hidden state `s_t` emits token `x_t`, then transitions to `s_{t+1}`. Easy, medium, and hard regimes share exactly the same transition matrix and differ only in emission overlap.

This construction gives exact access to:

* sampled hidden states
* the true transition matrix
* the true emission matrix
* predictive hidden-state beliefs `P(s_t | x_<t)`
* Bayes-optimal token distributions `P(x_t | x_<t)`
* exact same-position targets `P(x_t | s_t=k) = E[k]`

## Model

The canonical model is a two-layer causal transformer with `d_model=64`, four attention heads, and MLP width 128. A dedicated BOS token is provided as the only input at position zero. At position `t`, the model sees exactly `x_<t` and predicts `x_t`.

## Training

The model uses 1,200 training sequences and 250 separate model-validation sequences. Training runs for at least six and at most 30 epochs. It stops when model-validation cross-entropy is within `0.02` nats/token of the exact Bayes-optimal validation loss. The untouched analysis corpus is not used for model training or stopping.

## Analysis split

A separate 800-sequence analysis corpus is partitioned by whole sequence:

* 60% calibration
* 20% selection
* 20% untouched evaluation

No token positions from the same sequence cross these partitions.

Calibration sequences are used for probes, cluster discovery, cluster-to-state alignment, centroids, and SAE fitting. The selection split is reserved for optional model selection. The confirmatory fixed SAE does not tune on evaluation data. All reported final metrics use the untouched evaluation split.

## Predictive-belief probe

A ridge regressor maps activations to exact predictive belief vectors. Predictions are projected to the probability simplex by positivity clipping and row normalization. Reported metrics include KL divergence, MSE, variance-weighted R², argmax agreement, calibration error, and sampled-state agreement.

## Sampled-state probe

A deterministic ridge linear classifier maps calibration activations to sampled hidden-state labels and is scored on untouched evaluation sequences. The Bayes observable-state ceiling is the accuracy obtained by taking the argmax of the exact predictive belief.

## Discrete state abstraction

KMeans with `k=4` is fit on calibration activations only. Cluster-to-latent-state alignment is learned on calibration labels using the Hungarian assignment. The fitted KMeans object and fixed mapping are then applied to evaluation activations without using evaluation labels.

## Transition recovery

The transition matrix of the recovered evaluation-state sequence is compared against the generating HMM using:

* mean rowwise KL divergence
* Frobenius error
* stationary-distribution L1 error
* spectral error

Controls include shuffled recovered-state sequences and random state assignments.

## Markov-order evaluation

Order-0, order-1, and order-2 predictors are fit on recovered calibration-state sequences and scored on recovered evaluation-state sequences. The key diagnostics are order-1 improvement over order 0 and order-2 improvement over order 1.

## State forcing

State centroids are estimated from calibration activations. On evaluation sequences, the activation at the fixed intervention position is replaced by:

* the correct recovered-state centroid
* a wrong recovered-state centroid
* the global mean activation
* a random activation matched to centroid scale
* a deranged shuffled-label centroid
* an oracle centroid defined by sampled true states
* no intervention

The metric is `KL(exact target || post-intervention model distribution)`.

## Causal scrubbing

For each evaluation recipient, a donor activation is sampled from another sequence assigned to either the same recovered state or a different recovered state at the intervention position. MCT compares the KL shift in the output distribution caused by the two types of swaps.

## Observability sweep

The latent transition law is held fixed while emission overlap increases from easy to medium to hard. This isolates whether recoverability and causal state structure depend on how much the observation history identifies the hidden process.

## SAE comparison

A fixed sparse autoencoder is trained on calibration activations with hidden width 128, L1 coefficient 0.003, top-k 16, and two training epochs. The same held-out transition and belief metrics are applied to SAE features. No confirmatory hyperparameter sweep is performed.

## Seeds

The five confirmatory seeds are fixed as `[7, 17, 29, 43, 71]`. Every regime uses all five. No seed is excluded based on outcome.
