# Markovian Circuit Tracing

## Recovering latent state-transition structure from transformer activations

### Abstract

Mechanistic interpretability often explains model behavior through prompt-local circuits. Many model computations, however, unfold as trajectories through internal states. We introduce Markovian Circuit Tracing, a method for recovering probabilistic transition structure over internal model states. We validate the method on small causal transformers trained on sequences generated by a known Hidden Markov Model. This setting gives exact ground truth for latent states, transition dynamics, Bayesian belief states, and counterfactual next-token predictions. We show that transformer activations encode recoverable belief-state information, that clustered residual states recover latent transition structure better than shuffled and random controls, and that the recovered state sequence behaves approximately as a first-order Markov process. Activation state forcing further shows that some recovered states causally steer next-token predictions toward the exact HMM counterfactual. The experiment provides a controlled benchmark for testing whether circuit explanations can be represented as reusable probabilistic state machines rather than only prompt-local attribution graphs.

## 1. Introduction

Circuit tracing methods often give explanations for a particular prompt or behavior. This is useful, but it can miss a different structure. A model may move through recurring internal states, and those states may follow a transition law.

We ask whether such a transition law can be recovered from transformer activations.

The difficulty in ordinary language tasks is that the true internal state is unknown. We therefore start with a controlled Hidden Markov Model. The transformer observes only emitted tokens and is trained for next-token prediction. The true hidden states and transition matrix are known. The Bayes optimal predictor is also computable.

This gives a clean testbed for mechanistic interpretability.

## 2. Method

Let `a_l,t` be the activation at layer `l` and token position `t`. Markovian Circuit Tracing defines a state extractor `g(a_l,t) = z_t`, where `z_t` is a discrete internal state recovered from activations.

We estimate the transition matrix

```text
T_hat[i,j] = P(z_{t+1}=j | z_t=i)
```

and compare it to the true HMM transition matrix.

We use four tests.

1. State recovery from activations.
2. Transition-matrix recovery.
3. Markov-order comparison.
4. Counterfactual state forcing.

## 3. Benchmark

The benchmark uses a four-state HMM with six visible tokens. A small two-layer causal transformer is trained to predict the next visible token from previous visible tokens.

Since the data-generating HMM is known, we can compute:

- true latent states
- true transition matrix
- exact Bayesian belief vectors
- exact Bayes optimal next-token loss
- exact forced-state next-token targets

## 4. Metrics

We report:

- validation cross entropy
- Bayes optimal loss
- unigram baseline loss
- belief-probe MSE and KL
- latent-state probe accuracy
- unsupervised cluster accuracy
- rowwise transition KL
- Frobenius transition error
- stationary-distribution error
- spectral transition error
- order-0, order-1, and order-2 transition prediction accuracy
- forced-state KL

## 5. Main results

The first full run shows that the transformer reaches near-Bayes predictive loss. Residual activations encode recoverable latent-state and belief-state information. The recovered transition matrix is substantially closer to the true HMM transition matrix than shuffled and random controls.

The strongest Markovian result is that order-1 state transition prediction improves substantially over order-0 prediction, while order-2 prediction adds almost no gain. This supports the claim that the recovered state abstraction behaves approximately as a first-order Markov process.

## 6. Sparse autoencoder ablation

We also test sparse autoencoder feature states and Top-K sparse autoencoders. In the current experiments, residual-state MCT gives better transition recovery than SAE feature clustering. SAE features still recover state information above chance and beat shuffled and random transition controls, but they do not yet improve the main transition metric.

We treat this as an ablation rather than the headline result.

## 7. Limitations

The benchmark is synthetic. HMM dynamics are far simpler than language-model behavior. The recovered states are also not guaranteed to be unique. The method tests whether a state abstraction behaves Markovian, not whether all transformer computations are Markovian.

The experiment is still valuable because the ground truth is exact. It gives a rare setting where a mechanistic interpretability method can be tested against known latent dynamics.

## 8. Conclusion

Markovian Circuit Tracing turns circuit analysis into a state-transition recovery problem. On a controlled HMM benchmark, small transformers learn near-Bayes prediction, expose recoverable belief-state information in activations, and admit internal states whose transition dynamics are closer to ground truth than shuffled or random controls. This provides a small but rigorous benchmark for state-based mechanistic interpretability.
