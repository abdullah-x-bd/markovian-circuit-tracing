# Markovian Circuit Tracing

Markovian Circuit Tracing is a mechanistic interpretability experiment for recovering probabilistic state transitions inside small transformer models.

The core test is deliberately exact. We train a tiny transformer on sequences generated by a known Hidden Markov Model. Since the true latent states, transition matrix, emission matrix, and Bayes optimal next-token distribution are known, we can test whether an internal state model recovered from activations is predictive, Markovian, and causally useful.

## Research claim

A transformer trained on a process with known hidden Markov dynamics can learn internal feature states whose transition structure approximates the true latent transition matrix. Those states can then be tested with patching, state forcing, causal scrubbing, and transition-matrix recovery.

## Experiment spine

1. Generate synthetic sequences from a known four-state HMM.
2. Train a small causal transformer for next-token prediction.
3. Compute the Bayes optimal predictor for the same data.
4. Extract activations from layers and token positions.
5. Discover internal states from residual or MLP activations.
6. Estimate an internal transition matrix.
7. Compare it to the true HMM transition matrix.
8. Test the Markov property using order comparison and conditional mutual information.
9. Force internal states with activation patching.
10. Compare patched next-token predictions against exact HMM counterfactual targets.

## Why this is publishable

Most circuit tracing methods produce prompt-local graphs. This repo tests whether circuit tracing can produce a reusable probabilistic state machine.

The exactness comes from three facts.

1. The data-generating transition matrix is known.
2. The Bayes optimal next-token distribution is computable.
3. Counterfactual predictions under forced hidden states are computable.

## Run the first experiment

```bash
python experiments/run_full_hmm_pipeline.py
```

Expected outputs are written to `runs/hmm_4state_demo/`.

## Core metrics

- Hidden-state recovery accuracy
- Transition KL divergence
- Frobenius transition error
- Stationary-distribution error
- Spectral error
- Order-1 versus order-2 Markov score
- Counterfactual state-forcing KL
- Causal faithfulness score

## Main figure target

A five-panel figure should carry the paper.

1. True HMM transition graph
2. Recovered internal transition graph
3. Difference heatmap
4. Forced-state next-token prediction matrix
5. Same-state versus different-state causal scrubbing results

## Current status

This is a starter research repo. It contains the first complete experimental scaffold for the HMM validation benchmark. The next work is to run the pipeline, tune the transformer until it reaches near-Bayes loss, and then add SAE feature extraction as the main state representation.
